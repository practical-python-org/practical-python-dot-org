# The Practical Python blog!

As a community, we have decided to try our hand at a blog.

<!-- more -->

## What goes here

| Kind of post     | Example                                                          |
|------------------|------------------------------------------------------------------|
| Python releases  | For example, Python 5.15 just came out!                          |
| Tools            | A look at something like uv, ruff or a debugger                  |
| Things we built  | How a feature of the bot or this site works, and what went wrong |
| Community news   | Events, Code Adventure, changes to how the server runs           |

## What doesn't

If you have questions go into Discord, where someone can answer them. Anything that should stay true for years
goes in [Resources](../../resources/index.md) or the [tutorial](../../python-tutorial/index.md),
where people will look for it. A blog post is allowed to go out of date but we should try to keep resources updated. 

## Who writes it

The community, same as the rest of the site. A post is a Markdown file and a pull request. If you
worked something out last week and feel like sharing a win... make a blog post.
The [page about this site](../../projects/our-projects/this-site.md) covers how to build it locally, and
`CONTRIBUTING.md` in the repository has the front matter a post needs.

Not sure whether an idea is worth writing up? Ask in the [Discord]({{ discord_invite }}) first.

The first real post is about [Python 3.15](python-3-15.md).
