# Python Tutorial

## What is this?

This python tutorial section will attempt to teach you the core concepts of python in a
beginner-friendly manner. The way this tutorial is laid out allows you to read it in a contiguous
manner, connecting all the chapters in a smooth flow. You can look at the next page for the list of
topics to be covered.

## What is this not?

This is _not_ your typical "beginner to pro" tutorial scam and neither will we advertise it as so.
Any course, book or YouTube video that says so otherwise is probably a scam and can waste your time.
Building expertise comes from making projects yourself and learning every nitty-gritty things
yourself. You will not be able to achieve this just by reading this tutorial alone either, but we
will provide you a stepping stone to get started with this.
